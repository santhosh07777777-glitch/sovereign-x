# SOVEREIGN-X

**Verification-First Sovereign Agentic AI Workbench for Confidential Industrial Operations**

SOVEREIGN-X is an enterprise-grade AI workbench engineered for organizations such as industrial enterprises, PSUs, refineries, manufacturing plants, and defence organizations to analyze confidential engineering drawings, inspection reports, and sensor telemetry using secure, local, air-gapped agentic workflows.

---

## 🌟 Key Highlights

- **Verification-First Architecture**: Every assertion generated by specialized agents is independently cross-checked against physical sensor offsets, ground-truth document coordinates, and authorized Plant Standard Operating Procedures (SOPs).
- **10-Second Intuitive AI Workbench**:
  $$\text{UPLOAD} \longrightarrow \text{ANALYZE} \longrightarrow \text{AI PROCESS} \longrightarrow \text{VERIFY} \longrightarrow \text{EVIDENCE} \longrightarrow \text{FINAL RESULT}$$
- **4-Stage Vertical AI Pipeline**:
  - `AI Firewall`: Neural sanitization, adversarial prompt injection interceptor, and air-gap egress gatekeeper.
  - `Task Router`: Intent and multimodal asset dispatch engine.
  - `Knowledge Agent`: On-premise dense vector RAG over plant safety manuals and SOPs.
  - `Verification Agent`: Mathematical consistency checker and ground-truth cross-examiner.
- **Detailed Execution Drawer**: Deep slide-over enclave inspector displaying the complete 9-stage DAG, execution latencies (ms), model fingerprints (`gpt-oss-20B`, `Qwen3-VL-8B-Instruct`), isolated Python 3.11 sandbox logs, and cryptographic SHA-256 digests.
- **Split-Screen Document Viewer**: Interactive visual preview with bounding-box anomaly annotations and deterministic OCR text.
- **Interactive Evidence Graph**: Bidirectional provenance graph mapping tasks to raw document coordinates, extracted values, SOP rules, and verified results.
- **Human-in-the-Loop Verification Queue**: Formal review center with functional Approve, Reject, and Request Reverification actions.
- **Air-Gapped Tool Layer & Python Sandbox**: Isolated execution of industrial formulas (e.g., ISO 10816-3 Vibration Severity and Arrhenius oil life decay).
- **Multi-Format Deliverable Compiler**: One-click generation and local download of Word Reports (.docx), Executive Briefings (.pptx), Vibration Matrices (.xlsx), and Plant GM Approval Memorandums.

## 🚀 Getting Started

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/santhosh07777777-glitch/sovereign-x.git
cd sovereign-x
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build

```bash
npm run build
```

Production artifacts are compiled to the `dist/` directory.

---

## ☁️ Vercel Deployment

1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com/) and click **Add New Project**.
3. Import the `sovereign-x` repository.
4. Framework Preset: **Vite**
5. Root Directory: `./`
6. Build Command: `npm run build`
7. Output Directory: `dist`
8. Click **Deploy**.

## 🔒 Security & Air-Gap Architecture

SOVEREIGN-X enforces strict on-premise execution:
- Local GPU/Tensor inference simulation (`gpt-oss-20B`, `Qwen3-VL-8B`).
- Zero cloud telemetry or external outbound sockets (0 KB/s egress).
- Sandboxed deterministic code execution without host filesystem penetration.
